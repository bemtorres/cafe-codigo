# Propuesta de Curso: Desarrollo Web Backend con Django

## 1. Descripción general

El curso tiene como propósito desarrollar en los estudiantes las competencias necesarias para diseñar y construir aplicaciones web del lado del servidor utilizando **Python y Django**, incorporando progresivamente conceptos de arquitectura web, persistencia de datos, operaciones CRUD, seguridad y construcción de APIs RESTful.

El curso comienza con los fundamentos necesarios para comprender cómo funciona una aplicación backend y continúa con la implementación práctica de aplicaciones utilizando Django. Posteriormente, se incorporan bases de datos mediante Django ORM, administración de información mediante Django Admin y desarrollo de funcionalidades CRUD.

En una etapa avanzada, los estudiantes desarrollarán APIs RESTful utilizando Django REST Framework, incorporando mecanismos de autenticación mediante JWT y aplicando principios de seguridad para permitir la comunicación entre diferentes aplicaciones y servicios.

La propuesta busca que el estudiante no solamente aprenda la sintaxis del framework, sino que sea capaz de **analizar una problemática, diseñar una solución backend, implementar su lógica de negocio, persistir información y exponer funcionalidades mediante servicios web**.

---

# 2. Propósito formativo

Al finalizar el curso, el estudiante será capaz de desarrollar aplicaciones web backend utilizando Django, conectarlas a bases de datos, implementar operaciones CRUD, administrar información mediante Django Admin, aplicar mecanismos básicos de seguridad y construir APIs RESTful capaces de comunicarse con otras aplicaciones.

El curso busca desarrollar una progresión desde aplicaciones sencillas hasta una solución backend funcional y estructurada.

---

# 3. Competencias del curso

El estudiante será capaz de:

* Identificar los componentes fundamentales de una aplicación web del lado del servidor.
* Utilizar Python para resolver problemas mediante variables, operadores, estructuras de control y funciones.
* Comprender el funcionamiento de protocolos y servicios asociados a aplicaciones web.
* Configurar un entorno de desarrollo backend.
* Crear aplicaciones utilizando Django.
* Comprender la arquitectura de Django y su relación con el patrón MVC/MVT.
* Configurar rutas y vistas.
* Crear modelos y estructuras de datos.
* Utilizar Django Templates.
* Configurar conexiones con bases de datos.
* Utilizar Django ORM.
* Implementar operaciones CRUD.
* Utilizar Django Admin.
* Aplicar conceptos básicos de autenticación y autorización.
* Implementar mecanismos de seguridad en aplicaciones backend.
* Crear APIs RESTful.
* Utilizar Django REST Framework.
* Generar y consumir información en formato JSON.
* Implementar autenticación mediante JWT.
* Diseñar endpoints siguiendo principios REST.
* Construir una aplicación backend integrada.
